# MS001 — структурированные исходы offline shader translation

## Проблема

В проверенном upstream `apps/victory/src/translate.rs` может печатать отказы и завершаться `Ok(())`. Поэтому код выхода 0 недостаточен для автоматической приёмки. Это задача новой функциональности; готовые JSON/strict-result flags не предполагаются.

## Scope

Отчёт и политика исхода offline translation/warm-up. Не менять семантику emitter, shader coverage, GPU scheduler или ограничения циклов.

## Предлагаемый контракт, который нужно согласовать с исходниками

- Дополнительный machine-readable report с версией schema.
- SHA translator, hashes входов, режим validate/pipeline/cache, количество examined/translated/validated/PSO-created/refused и причины.
- Отдельные статусы для отсутствующего validator/adapter, неподдерживаемой инструкции и реальной внутренней ошибки.
- Нельзя выводить PASS, когда обязательная стадия проверки не выполнялась.
- Опциональный строгий aggregate exit: ненулевой исход при любом требуемом refused/failed/blocked; нулевой только при выполненном заявленном контракте.
- Человекочитаемый output и прежнее поведение сохраняются, если новый режим не выбран, насколько это соответствует проектной политике.
- `--cache` по-прежнему нельзя объединять с конфликтующими `--validate`/`--list` без отдельного решения.

Имена новых flags/типов выбираются после просмотра CLI. Не писать инструкции запуска несуществующего флага до его реализации.

## Проверки

Создать разрешённые synthetic inputs: один поддерживаемый, один неподдерживаемый, один повреждённый. Проверить counters, per-case reason и aggregate exit. Проверить сценарий отсутствующего validator и неполного результата. Для reporting tests не нужна игра и не обязательно нужен GPU; PSO stage требует отдельной QA.

## Передача

Implementer передаёт candidate SHA, schema/example, команды. Reviewer проверяет, что report отражает реальную control flow и не потерял ошибки в warm-up. GPU QA нужен только для изменённой аппаратной стадии, если такая затронута. Новая схема не считается доказательством правильности самих шейдеров.
